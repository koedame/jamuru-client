# UI 用語集

UI の文言の表記揺れを防ぐための正規語彙。新しい画面・コンポーネントを作るときと、`ui/locales/{ja,en}.json` に文言を足すときに参照する。

文言の正本は `ui/locales/` の実装。この用語集は、その文言に共通する規則を書き出したもの。食い違いを見つけたら、実装の文言を確かめてからどちらを直すか決める。

---

## ルーム・セッション

| 概念 | 日本語 | 英語 | 備考 |
|---|---|---|---|
| ルーム | ルーム | Room | 「部屋」は使わない |
| 招待コード | 招待コード | Invite Code | 「ルームコード」とは書かない |
| 参加者 | 参加者 | Participant | 「メンバー」は使わない |
| 自分（ミキサーのチャンネル名） | 自分 | You | 「(あなた)」とは書かない |
| 作成者 | 作成者 | — | ルームを作成した参加者。「ホスト」という特権的な概念は持たず、他の参加者とはフラットな関係（[ADR-016](../adr/ADR-016-remove-host-privilege-concept.md)） |

## 入退室

「退出」と「退室」は意図的に使い分ける。統一しない。

| 用語 | 用途 |
|---|---|
| 退出 | 退出ボタン（確認ダイアログを開くだけの短い動詞）。チャットのシステムログ「{{name}}さんが退出しました」 |
| 退室する / 本当に退室しますか？ / 退室処理中... | 確認ダイアログ内の実行文言（実際にルームを離れる動作） |
| 参加 | 招待コードでルームに参加するボタン。チャットのシステムログ「{{name}}さんが参加しました」 |

チャットのシステムログに「入室しました」「退室しました」は使わない。

## 接続ステータス

| 状態 | 日本語 | 英語 |
|---|---|---|
| 未接続 | 未接続 | Disconnected |
| 接続試行中 | 接続中...（末尾の `...` で「接続済み」と区別する） | Connecting... |
| 接続済み | 接続中 | Connected |
| 切れた | 切断されました | Disconnected |

「接続済み」の状態を「接続中」と書くのは意図的（日本語では進行形の「接続中」が「つながっている最中」を表す）。試行中との区別は `...` で付ける。

## 数値フォーマット

| 単位 | 表記 | 備考 |
|---|---|---|
| ミリ秒 | `12ms`（スペースなし） | 「12 ms」は使わない |
| サンプルレート | `48kHz`（スペースなし） | |
| バッファサイズ | `64 samples`（スペースあり） | samples の前だけはスペースを入れる |
| マイクロ秒 | `0.93 µs`（スペースあり） | |

### 実装で表記が揺れている箇所

- 日本語のバッファ選択肢（`settings.devices.bufferOption`）は「64 サンプル (1.33ms)」。同じ値を出す `settings.audio.bufferValue` は「64 samples (1.33ms)」
- 音声設定のフォールバック表示（`useAudioSettingsTab.ts`）は「48 kHz」（スペースあり）
- 診断の「送らないもの」（`settings.diagnostics.usageNotSent`）だけ「部屋」を使っている

## 空状態の文言

責めるようなトーンを避ける（「何もありません」ではなく「〜はまだありません」）。次にやることがあれば添える。

| 場所 | 日本語 |
|---|---|
| チャット | メッセージはまだありません |
| ルーム一覧 | まだルームがありません |

## ボタンの語彙

| アクション | 日本語 | 備考 |
|---|---|---|
| キャンセル | キャンセル | 「取消」は使わない |
| コピー | コピー / コピーしました（コピー後） | |

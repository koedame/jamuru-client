# PeerLinkDetail コンポーネント

参加者 1 人との音声が通る層を、自分のデバイスから相手のデバイスまで層ごとに出す。

---

## 概要

**目的**: 遅延が大きいときに、どの層（自分のデバイス・ネットワーク・相手）が効いているかを見分けられるようにする。
参加者が複数いると層ごとの値は人ごとに違うので、接続済み画面のフッターには出さず、参加者の行を押して開く。

**使用場面**: 接続済み画面のサイドバーで、自分以外の参加者の行を押したとき、その行の下に開く
（`ui/src/screens/MainScreen.tsx`）。開けるのは 1 人ぶん。同じ行をもう一度押すか、別の参加者の行を押すと閉じる。

---

## Props / API

| Prop | 型 | 必須 | 説明 |
|------|-----|------|------|
| peerName | string | ✓ | 参加者の名前（相手の層の見出し） |
| link | PeerLinkStatus \| undefined | ✓ | その参加者との音声の接続。まだ無ければ undefined |
| localSampleRate | number | ✓ | 自分のサンプルレート（Hz）。相手と違うときのリサンプリングの知らせに使う |
| id | string | - | 開く行の `aria-controls` から指す id |

---

## 表示する層

| 層 | 行 | 値の出どころ |
|----|----|-------------|
| 自分 | 入力 / 出力 / ジッターバッファ | `link.latency` の Capture buffer / Playback buffer / Jitter buffer |
| ネットワーク | 往復 / ジッター / パケットロス | `link.network` |
| 相手（名前） | 入力 / 出力 / ジッターバッファ / 音声の形式 | `link.peer_audio`（相手が知らせた値） |

- 10ms 未満は小数 1 桁（0.7ms）、10ms 以上は整数に丸める（丸めて 0ms になると何も伝わらないため）
- まだ値が無い行は「測定中...」と出す。往復を測る前（`rtt_ms` が null）の往復も同じ（REQ-LAT-130）
- 相手のサンプルレートが自分と違うときは、リサンプリングしている旨を黄色で添える
- 合計の ↑/↓ は行の見出し側に出ているので、ここでは繰り返さない

---

## 状態

| 状態 | 表示 |
|------|------|
| Default | 全部の層に値がある |
| Empty（リンクが無い） | 全部の値が「測定中...」 |
| Partial（往復が未測定） | 往復だけ「測定中...」 |
| Resampling | 相手の形式の下に黄色の知らせ |

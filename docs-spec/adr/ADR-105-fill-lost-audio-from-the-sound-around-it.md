# ADR-105: 失われた音を、前後の波形と線形予測で補う

## Status

Accepted（欠損の補い。既定 ON。供給が止まったときの予測（下の Decision 3）も既定 ON）。ドラムで従来より悪い指標があるが、メンテナーが 11/11 に、ドラムを除外せず既定 ON にすると決めた（Consequences）。

## Context

FEC（[ADR-021](./ADR-021-preset-codec-and-fec.md)）で直せなかった損失は、再生バッファ（[ADR-028](./ADR-028-single-stage-playout.md)）が次のとおり埋めていた。

- 後続のフレームが届いているのに、そのフレームだけ無い（`Concealed`）: 直前のフレームを繰り返して 1 フレームのうちにフェードアウトする（`PcmPlc`）
- 後続も届いていない（`Starved`）: 無音（[ADR-026](./ADR-026-gui-audio-path.md)。位置は進めない）

繰り返しは、音程が変わる声や和音では位相が合わず、フェードアウトで音量も落ちるので、損失の場所が「プツッ」と聞こえる。無音は、歌の語尾や持続音の途中で聞こえる穴になる。穴の前後の波形から、もっと近い音を作れる。

守ること: 遅延を足さない（[AGENTS.md](../../AGENTS.md) の最優先要件）、音声コールバックで確保・ロック・待ちをしない、損失の無いフレームには手を触れない。

## Decision

穴の種類で方法を分ける。どちらも `src/audio/conceal.rs` の `Concealer` が持つ。数値は 48 kHz のときの値で、他のレートでは時間（ms）が同じになるよう換算する。

1. **欠損（後続が届いている）は、前後の波形から補う。** 材料は 2 つ。
   - **過去のコピー**: 直近 5120 サンプル（約 107 ms）の履歴から、穴の直前の 48 サンプルと、穴の直後のフレームの先頭 48 サンプルの両方に正規化相関が最も高い位置（遅れ 32〜512 サンプル）を探し、そこからの波形を穴の長さだけ周期的に写す。相関が 0.6 未満なら使わない。負の相関なら符号を反転する。音量は直前 48 サンプルのエネルギー比で合わせる（4 倍まで）。先頭は、直前の最後のサンプルとの段差を 32 サンプルかけて消す。後続フレームとの境は 64 サンプルの線形クロスフェードにする
   - **前後からの予測**: 履歴の最後 10 ms（Hann 窓、次数 16 の線形予測、Levinson-Durbin、反射係数は ±0.999 に制限、係数は 0.999 の k 乗で広げる）から、穴の手前の側へは順方向、穴の後ろのフレームの側へは逆方向に同じ係数で予測し、穴の中で一方からもう一方へ線形に移す。穴の周りより 1.5 倍を超えて大きくなる予測は使わない（共振が鋭いと途中でふくらむことがある）
   - **選び方**: 過去のコピーの相関が 0.95 以上ならコピー。それ未満なら、コピーと予測の差が予測のエネルギーの 30 % 未満のときにコピー、そうでなければ予測（コピーと予測が合うなら、波形が正確なコピーを選び、合わなければスペクトルがふつう外れない予測を選ぶ）。コピーも予測も作れなければ従来の繰り返しに戻す
2. **補う長さの上限は履歴の長さ（約 107 ms）。** 連続して長い穴は、従来どおり繰り返し・フェードアウトに戻す。
3. **供給が止まった（後続も無い）ときは、過去から予測する。** 直近 10 ms の線形予測（ピッチ強調 0.97、Hann 窓、次数 16、反射係数 ±0.999、係数は 0.99 の k 乗で広げる）で音を延ばす。ピッチ（60〜800 Hz、直近 38 ms の相関、粗い探索は 4 サンプル刻み、相関 0.3 以上を候補、0.4 以上を採用、約数の周期は 0.92 倍の規則、放物線補間）が見つかれば、直前 1 周期の繰り返しを重みで混ぜる（重み = min(0.6, 相関 × 0.7) × (相関 − 0.55) / 0.25。後ろの係数は 0〜1 に収める）。ピッチの繰り返しは線形予測の再帰の中に入れず、別の履歴に置いて出力で混ぜる（再帰の中で混ぜると発散した）。包絡は 10 ms 保持し、周期性に応じて 30〜120 ms でフェードアウトする。振幅が 2 を超えたら発散として打ち切る。最初のサンプルは、直前のサンプルの向かう先に合わせ、32 サンプルかけて予測に移す。本物の音が戻るときは、予測を 64〜240 サンプル（周期性が高いほど長く）かけて本物にクロスフェードする。**既定は ON**（`ReceivePath::set_starved_prediction(false)` で従来どおりの無音に戻せる）。ミュートした送り手の最後の言葉を残響のように鳴らさないよう、読み出しが 375 回（約 0.5 秒）空のまま続いた後は予測しない
4. **効きすぎを止める。** 直近の読み出しの欠け率（時定数 1 秒の指数平均）が 8 % を超えたら、予測（Decision 3）を止める。2 % 未満が 3 秒続いたら戻す。損失の多い回線では、予測が続けて外れて耳障りになるのを避ける。欠損の補い（Decision 1）は後続フレームを見て作るので、この制限は受けない
5. **遅延を足さない。** 欠損の補いは、再生バッファがすでに持っている後続フレームを見るだけで、後続を待たない。読み出しの結果（`Played` / `Concealed` / `Starved` / `Padded` / `Priming`）、順序、長さは補いの ON・OFF で変わらない（REQ-AUD-072）。バッファの段数は変わらない
6. **音声コールバックで確保しない。** バッファはすべて `Concealer::new` で確保する。補いの ON・OFF の切り替えと作り直しは、音声コールバックの外で行う。損失の無いフレームは、予測のすぐ後（本物の音が戻るときのクロスフェード）を除き、ビット単位で変わらない
7. **補った音は切れ目として扱わない。** 受信経路は、補った読み出しの前後に入れていたクロスフェード（REQ-AUD-041）を、補いが作った音のときは省く。補いの側が前後に合わせてあるため
8. **測定のために切り替えられる。** `ReceivePath::set_waveform_concealment(false)` で従来の繰り返し・無音に戻る。画面の設定には出さない
9. **補った音は、それまでに再生した音の最大値（フルスケールまで）を超えない。** 過去の写しは、レベルを直前に合わせる倍率（上限 4）と、写す区間の最大値が上限を超えない倍率の小さい方で掛ける。写しの出力と末尾、前後からの予測、延長の出力と末尾は、最後に履歴の最大値で切る。補った音は再生され、次の補いの過去として履歴に入るので、切らないと倍率が重なって振れ幅が育つ（敵対的な音と欠けの組み合わせで、フルスケールの約 12 倍まで育つのを再現した）。切るのは、倍率を抑えても残る、直前のサンプルに合わせる段差や予測の行き過ぎだけ

却下した案:

- **前後からの予測だけ**: 和音・撥弦・ドラムのスペクトルは最も近いが、持続音（弓で弾く音・声）では波形の誤差が大きく、過去のコピーの方が SNR で 20 dB 以上良い
- **過去のコピーだけ**: 持続音では最良だが、相関が不十分な和音・撥弦・ドラムでスペクトルが外れ、予測の方が近い
- **ピッチの繰り返しを線形予測の再帰の中で混ぜる**: 出力の最大値が正解の 4〜6 倍になり、SNR が −9 dB まで落ちた（再帰の中で混ぜると共振が増幅される）
- **長さの上限を 130 ms より長く／バッファ目標の 2 倍にする（欠損の補い）**: 履歴が 107 ms なので、それ以上は繰り返しになり、従来に勝てなかった
- **後続のフレームを待って両側から補う**: 遅延が増える（Decision 5）

## Consequences

### 測定した品質

人工的に壊した音（式で作った 5 種: 撥弦・歌声・和音・ドラム・弓の持続音。録音を使わないので許諾の問題が無い）で、旧（繰り返し・フェード）と新を同じ損失で比べた。`tests/conceal_measure.rs`（`cargo test --release --test conceal_measure -- --ignored --nocapture`）。

指標: 失われたフレームの SNR（正解との誤差。大きいほど良い）、全体の SNR、スペクトル距離（穴の前後 4 フレームを含めた 512 サンプルの窓の対数スペクトル差。小さいほど良い。正解の最大値より 70 dB 低い成分は数えない）、つなぎ目の段差（95 パーセンタイル、その場の音の通常の変化量に対する比。壊していない音そのものの値と比べる）。

**欠損（フレームが失われ、後続は届いている。受信経路を通した測定）**

|---|---|---|---|---|---|
| 撥弦 | 1.8 % | −1.56 → 0.68 | 15.00 → 17.86 | 9.14 → 5.85 | 3.71 → 5.21（6.78） |
| 撥弦 | 5.9 % | −1.20 → 0.62 | 9.88 → 12.44 | 9.32 → 5.97 | 5.11 → 6.54（7.04） |

| 歌声 | 5.9 % | −2.09 → 9.24 | 9.20 → 21.36 | 6.19 → 1.98 | 1.83 → 2.09（1.97） |
| 和音 | 1.8 % | −1.86 → 0.63 | 14.62 → 17.93 | 9.82 → 7.92 | 3.59 → 4.24（4.78） |
| 和音 | 5.9 % | −1.74 → 0.34 | 10.23 → 13.21 | 9.78 → 7.62 | 3.09 → 4.13（4.41） |

SNR とスペクトル距離は 5 種すべてで旧より良い。つなぎ目の段差は旧より大きいが、旧は音を 1 フレームでフェードアウトして段差を小さくしているだけで、新は壊していない音そのものの値（括弧内）とほぼ同じ（ドラムだけ 2.39 対 2.03 などわずかに上）。

穴 1 つだけを直接補った場合（634 か所、正解の 1 フレームと比べる）は、SNR が撥弦 −2.0 → 1.1、歌声 −3.9 → 24.6、和音 −3.1 → 1.7、ドラム 1.0 → 7.1、弓 −3.8 → 26.8 dB、スペクトル距離が 20.7 → 4.9、24.2 → 2.8、25.5 → 6.2、7.5 → 2.5、26.8 → 0.65 dB。

| 歌声 | 短 | 0.07 → 10.00 | 5.10 → 2.90 | 1.26 → 1.26 |
| 歌声 | 長 | 0.21 → 8.48 | 5.44 → 3.12 | 1.69 → 1.98 |
| 和音 | 短 | −0.49 → −0.15 | 9.96 → 5.07 | 1.55 → 1.57 |
| 和音 | 長 | −0.22 → 0.15 | 10.27 → 5.50 | 2.29 → 2.29 |
| ドラム | 短 | **3.49 → 1.11** | **7.14 → 8.18** | 4.10 → 3.02 |
| ドラム | 長 | 1.32 → 2.95 | **6.53 → 6.97** | 3.45 → 3.02 |
| 弓の持続音 | 短 | 0.47 → 7.54 | 3.77 → 1.78 | 0.84 → 2.84 |
| 弓の持続音 | 長 | 0.40 → 7.94 | 4.46 → 1.97 | 0.78 → 2.86 |

4 種では旧より良いが、**ドラムでは短い止まりの SNR とスペクトル距離、長い止まりのスペクトル距離が旧より悪い**（太字）。ドラムは直前の音から次の打撃を予測できず、旧の無音（実際には旧は 3.49 dB 出ている。止まりの直前が打撃の余韻のため）の方が近いことがある。弓の持続音のつなぎ目の段差（0.8 → 2.8）も旧より大きいが、その音の壊していない値（4.7）より小さい。それでも予測（Decision 3）は既定 ON とした。4 種で大きく良くなり（無音ではなく続きの音が鳴る）、悪くなるのはドラムの一部の指標だけで、聞こえ方の違いは打撃の直後の短い余韻に限られるため。ドラムだけ除外する仕組み（音の種類の判定）は足さない。

### 処理時間

最適化ビルドで 1 回の補い（64 サンプルのステレオ。1 フレーム 1333 µs）: 欠損の補いが平均 85 µs・最悪 148 µs、過去からの予測が平均 60 µs・最悪 127 µs（`how_long_filling_a_gap_takes_next_to_the_time_a_frame_lasts`）。最悪でも 1 フレームの 11 %。

### 遅延

補いは読み出しの結果・順序・長さを変えない（REQ-AUD-072）。バッファの段数、`ConnectionStats` と遅延の内訳（`roundtrip_total_ms` を含む）の算出に使う値は何も変えていない。遅延は補いの ON・OFF で同じ。

### 残る制約

- 欠損の補いの上限は約 107 ms。それ以上続く穴は従来の繰り返し・フェードアウトになる
- 欠損の補いのテストは 5 種の式で作った音による。実際の楽器・声での聞こえ方は、聴き比べ用の WAV（`target/conceal-wavs`、`JAMUMU_CONCEAL_OUT` で変える）で確かめる
- 補いと予測の定数は、5 種の音での測定から決めた出発点。別の種類の音（打楽器の連打・ノイズ主体の音）で外れたら、測り直して決め直す

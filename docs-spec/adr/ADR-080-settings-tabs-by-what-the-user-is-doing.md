# ADR-080: 設定のタブは「利用者がしたいこと」で分ける

## Status

Accepted

[ADR-037](./ADR-037-usage-reporting-opt-in.md)・[ADR-056](./ADR-056-hang-detection-and-reporting.md) が置き場所とした「Diagnostics タブ」と、[ADR-072](./ADR-072-terms-of-use-and-first-launch-consent.md) が置き場所とした「一般タブ」は、この ADR で置き換える。それぞれの決定（既定はオフ・ダイアログを出さない・規約の行を置く）は変わらない。

## Context

設定のタブは「一般・デバイス・プロフィール・診断」の 4 つで、項目が増えるたびに近い場所へ足してきた。その結果、次のずれが出た。

- **診断タブが 4 つの別の用事を持っていた。** システム診断（自分の環境を調べる）、利用状況の送信と前回の異常終了の報告（データを送るかの判断）、ログのフォルダを開く、問題を報告（困ったときの連絡）。診断を実行したい人と、送信を止めたい人は別の場面で来る
- **一般タブが言語・サーバー・規約を持っていた。** 規約・ライセンス・お知らせは設定ではなく「このアプリについて」の情報で、設定の項目と並べると読み分けにくい
- **プロフィールタブは項目が表示名 1 つだけだった。** タブ 1 つの重さに見合わない
- **「デバイス」タブの題が中身より狭い。** 入出力デバイスのほか、送信チャンネル・サンプルレート・バッファサイズ・遅延の目安を持つ

## Decision

タブは「利用者がそこで何をしたいか」を軸に、次の 5 つに分ける。項目は減らさず、置き場所だけを変える。

| タブ（日本語） | id | 項目 |
|---|---|---|
| 一般 | `general` | プロフィール（表示名）／表示（言語）／接続（サーバー） |
| オーディオ | `devices` | デバイス（入出力デバイス・入出力チャンネル）／音質と遅延（送信チャンネル・サンプルレート・バッファサイズ・遅延の目安） |
| プライバシー | `privacy` | 前回について（異常終了の報告を送るか）／利用状況の送信 |
| 診断とサポート | `diagnostics` | システム診断／ログファイル／問題を報告 |
| アプリについて | `about` | 規約など（利用規約・ライセンス・プライバシーとセキュリティ・お知らせ） |

- 並びは使う頻度の順（よく触る設定 → 送信の判断 → 困ったとき → 情報）。設定ウィンドウを開いたときの初期表示は、これまでどおり一般である
- プロフィールタブは無くし、表示名は一般タブの先頭の節にする
- `devices` の id は変えない。DOM の id・E2E・設定の手伝い（ADR-044）がこの名前で参照している。表の題だけを「オーディオ」にする
- 「アプリについて」は、規約の行を渡されたときだけ出る（`legal` を渡さない部品の単体表示では出さない）
- 利用状況と前回の報告の i18n キーは `settings.privacy.*`、E2E 用の `data-testid` は `privacy-*` に移す

## Consequences

- 利用状況の送信を止めたい人は、診断を開かずに「プライバシー」で見つけられる。利用者向けの説明（`docs/getting-started/privacy.md`・`troubleshooting.md`）の、タブの名前を直す
- ADR-037 の「Diagnostics タブ」、ADR-056 の「Diagnostics タブの案内」は、「Privacy タブ」と読む
- `ui.pen` の設定画面（`Screens/Settings` の各フレーム）は、この 5 タブに描き直した

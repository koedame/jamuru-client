# ADR-049: デバイスへのチャンネルの当てはめは開くときだけ。同じ番号の組は 1 チャンネル。受け手のパンは届いた音に合わせる

## Status

Accepted。[ADR-040](./ADR-040-input-output-channel-selection.md) の 2 の末尾（右が未設定なら左を両側に送る）と 5（デバイスに合わせた当てはめ）を置き換える。[ADR-038](./ADR-038-transmit-channels-select-capture.md) の 3（2 チャンネルで開けなければ 1 チャンネルで開き直す）は、当てはめでも開けなかったときの安全網として残る。

## Context

Mac 実機（beta.17）で ADR-038 のステレオ送信を確かめ、3 つの欠陥が見つかった。

1. **受け手のパンが、中央でも左右を混ぜる。** 受け手は、中央で左右とも 0.707 倍にしたうえで、反対側を 0.293 倍して足していた。モノラルの送り手は左右が同じ音なので合計が 1 倍に戻るが、左だけに音があるステレオの送り手では、左が右へ −7.7 dB で漏れ、左自身も −3 dB 下がった（実測: 送る直前は左 −10.5 dB・右は無音、受け手では左 −13.5 dB・右 −21.1 dB）。送り手が左右を混ぜずに送っても、受け手が混ぜていた。
2. **モノラルのデバイスで、1 チャンネルで開き直す分岐に届かなかった。** ADR-040 の当てはめは、デバイスが 1 チャンネルなら組を (1, 1) にした。取り込みは (1, 1) を「同じチャンネルを 2 つ」として 2 チャンネルで開いて成功するので、ADR-038 の「2 チャンネルで開けなければ 1 チャンネル」に入らず、帯域は 2 倍のまま、相手の表示もステレオのままだった。
3. **モノラルのマイクを一度選ぶと、保存した組が (1, 1) に書き換わった。** ステレオの機材に戻しても (1, 1) のままで、右の音が失われる。持ち主には見えない。

2 と 3 は同じ根から来ている。ADR-038 の「取り込むチャンネル数」と、ADR-040 の「デバイスに合わせた組の当てはめ」を、別々の場所が、別々の時に決めていた。

## Decision

1. **デバイスへの当てはめは、そのデバイスを開くときだけ行う。** 保存した組（利用者が選んだもの）は書き換えない。入力・出力とも、デバイスを開く処理（`start_capture_ring` / `start_playout`）が、保存した組を開くデバイスのチャンネル数に当てはめる（`pair_in_use`。持っていれば保存した組、持っていなければ先頭の組。申告しないデバイスは保存した組のまま）。デバイスを切り替えるコマンドは組に触れない。
2. **設定画面には、いま使っている組を表示する。** 保存した組が 5・6 でも、2 チャンネルのデバイスを使っていれば 1・2 と出る。片側のチャンネルを変えるときは、表示している組から始める。元のインターフェースに戻せば、保存していた 5・6 が使われ、表示される。
3. **入力は、左右が別のチャンネルのときだけ 2 チャンネルで取り込む。** 右が未設定、または左右が同じ番号なら、1 チャンネルで取り込み、相手にもモノラルと伝える（同じ音を 2 つ取り込んでステレオと偽らない）。1 チャンネルのデバイスも、当てはめで (1, 1) になるので、この規則で 1 チャンネルになる。ADR-038 の「右が未設定なら左を両側に送る」は、モノラルの取り込みをパンで両側に置く形になる。
4. **受け手のパンは、相手が送っているチャンネル数で意味が変わる。** 相手がステレオなら、左右は相手自身の音像なので、パンは左右バランス（向いた側は変えず、反対側を下げる。中央は素通し）。相手がモノラルなら、相手が自分のパンで置いた左右を、従来の等パワーのパンが動かす。相手のチャンネル数は、相手が知らせてくる `channel_count`（知らせない古い相手は 2）を、受信経路（`ReceivePath`）が持つ。出力コールバックはロックなしで読む。

## Consequences

- REQ-AUD-120（受け手のパン）・REQ-AUD-121（同じ番号の組は 1 チャンネル）・REQ-AUD-122（当てはめは開くときだけ。保存は書き換えない）の検証は、単体テストと、線路を通した結合テストで行う。
- 送り手のバランス（`capture_to_wire`）と受け手のバランスは、同じ関数（`balance_gains`）を使う。
- 接続中にデバイスを切り替えると、セッションはデバイスを開き直すときに当てはめる。以前は設定の変更が組も送っていたが、送らなくなった。
- 実デバイスを開く部分は自動テストの外にある。Mac 実機で新しい版を確かめる（`Plans.md`「実環境待ち」）。

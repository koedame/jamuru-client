# ADR-065: 入り直しのあと、音声は名簿の旧エントリではなく、いま聞こえる相手へ張り直す

## Status

Accepted

## Context

シグナリングの接続だけが切れた（RST）あとの入り直しで、音声が戻らなかった。3 分続いたセッションが途中で止まり、そのまま戻らなかった。
暗号化（[ADR-064](./ADR-064-encrypt-the-audio-link.md)）とは関係がなく、入れる前も同じ形で起きる。

原因は、サーバーが切断に気づくまで、切れた参加者のエントリが名簿に残ることと、アプリがそれを前提にしていなかったことの 2 つ。

1. **入り直した側が、名簿に残った自分の旧エントリを音声の相手に選んでいた。** 入り直すと新しい ID で入るので、名簿には旧エントリと相手の
   2 つが載る。音声の相手は「アドレスを公開している先頭の 1 人」で、先頭は旧エントリ（自分）だった。自分の旧アドレスへ送り、誰にも届かない。
   旧エントリは参加者の一覧にも載った。
2. **残った側が、入り直した相手に追従できなかった。** 音声は「すでに誰かと流れている間は、新しいアドレスを使わない」ので、新しい ID の
   相手がアドレスを公開しても無視し、旧エントリへ送り続けて黙った。10 秒で諦めたあとも、誰も張り直さない。

退室の知らせ（`PeerLeft`）が来れば `Roster::left` が音声を止めて次の相手へ移すが、RST で切れた接続のエントリは、サーバーが気づくまで
退室の知らせを出さない（実測で 40 秒近く残った）。知らせを待つ設計では、その間ずっと音が戻らない。

## Decision

1. **自分が過去に使った ID を覚え、入室のたびに名簿から外す。** 旧エントリは相手でも参加者でもない（`Roster::entered`）。
2. **音声の状態を名簿に伝え、止まったら張り直す。** セッションは音声接続の状態（`reconnecting`・`failed`）を、シグナリングのイベントを読む
   ループで一緒に読む。
   - `reconnecting`（2 秒の無音）: 同じ名前の参加者が別の ID でアドレスを公開していれば、そちらへ移す。同じ相手が別のアドレスを公開していても移す。
     名前が違う参加者へは移さない（働いている回線の数秒の途切れで、別の人へ乗り換えない）。
   - `failed`（10 秒の無音で接続が諦めた）: アドレスを公開している誰かがいれば、名前を問わず移す。誰もいなければ待ち、公開された時点で移す。
   - 一度離れた相手へは、その相手が新しいアドレスを公開するまで戻らない（旧エントリ同士を行き来しない）。
3. **移すとき、自分の音声アドレスは変えない。** 音声を止めたあと、同じポートでソケットを取り直し（`Audio::KeepAddress`）、取れなかったときだけ
   公開し直す。移る先の相手は、こちらの公開済みのアドレスへ向かっている。公開し直すと、相手がその新しいアドレスへ張り直し、こちらがまた
   相手の新しいアドレスへ張り直す、と互いに追いかけて収束しない。
4. **音声を止めるときは、音声のスレッドが終わるのを待つ。** 固定の 100 ms ではない。スレッドは最後に「動いている」の旗を下ろす。待たずに
   次の音声を始めると、前のスレッドの終わりが次のセッションの旗を下ろし、始めた音声が接続した直後に終わる（移す操作が必ず通る経路なので
   見つかった。名簿が相手を替えるたびに止めて始める）。

## Consequences

- RST で切れた接続のエントリがサーバーに残っていても、入り直しの 3〜5 秒後に、双方向の音が戻る。
  検証: ルームを作る側・入る側のどちらの接続を切っても戻る（アプリ 2 台とローカルのシグナリングサーバーの間に置いた TCP プロキシで、片方の
  接続だけを RST で切り、サーバー側は開けたままにした）。変更前は、どちらも `failed` のまま戻らなかった。
- 定常の音声経路（送受信・バッファ・符号化）は変えていない。変わるのは、止まった回線を張り直すときだけ。
- 既知の限り: 同じ名前の別人（既定の名前のまま入った 2 人）が、片方が 2 秒途切れたときにもう片方へ移されうる。3 人以上のルームは音声が
  1 対 1 で、音の相手以外は聞こえない仕様なので、この場合に失うものは小さい。
- サーバーが同じ端末の古いエントリを入り直しで追い出す（端末 ID は署名付きで渡っている）ようにすれば、`PeerLeft` が即座に届き、アプリ側の
  追従に頼る時間が縮む。アプリ側の追従は、サーバーが古い版のとき・追い出す前のわずかな間のために残る。

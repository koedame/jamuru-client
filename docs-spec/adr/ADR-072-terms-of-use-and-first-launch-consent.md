# ADR-072: 利用規約はアプリに同梱し、初回起動で同意を取る。同意するまでアプリは何もネットワークに出さない

## Status

Accepted。

## Context

jamjam には利用規約が無かった。不特定の人が使い始める 1.0.0 の前に、契約の内容として規約を相手に示し、同意を取る必要がある。経済産業省の準則（電子商取引及び情報財取引等に関する準則）と民法の定型約款（第 548 条の 2〜4）は、規約を契約の内容にするのに、利用者に**個別に**その旨を示すことを求める。ホームページに載せるだけでは足りない。規約へのリンクを張るだけでは、利用者に電磁的記録で提供したことにならない。

同意を取る場所の候補は、インストーラ・初回起動の画面・文書サイトだった。インストーラの同意画面があるのは Windows の MSI だけで、macOS の dmg・Linux の AppImage と deb には作れない。同意の記録も残らない。アプリには申込みの画面が無く、利用の入口は初回起動である。

もう 1 つの問題は、アプリが起動と同時に自分でネットワークへ出ることだった。サーバーへの接続、更新の確認（GitHub）、利用状況の送信、ベータ版の遠隔デバッグの問い合わせである。同意画面を出しても、その裏で端末の IP アドレスや版が先に相手に見えるなら、同意の前に情報が出ている。

## Decision

1. **規約は同じ文面で 2 か所に置く。** 文書（`docs/terms.md`。公開は正式版のとき）と、アプリへの同梱（設定画面と同意画面で読む。オフラインでも読める）。正本は `docs/terms.md` で、アプリはビルド時にそのファイルを取り込む（`src-tauri/src/terms.rs` の `include_str!`）。Windows インストーラのライセンス画面に「規約は初回起動のときに同意いただく」と 1 行案内する案は、この変更に含めていない。
2. **同意は初回起動の最初の画面で取る**（`ConsentScreen`）。規約の本文（スクロールできる）・チェックボックス 2 つ（規約への同意／18 歳以上、または親権者の同意）・ボタン 1 つ。2 つにチェックが入るまでボタンは押せない。画面の上に、同じルームの人に IP アドレスが見えることを 1 行で出す。同意しないときは画面を閉じる（何も保存しない）。
3. **同意した版を設定ファイルに記録する**（`terms_version`・`terms_accepted_at`。端末の外には送らない）。アプリが期待する版は `jamjam::config::TERMS_VERSION` で、`docs/terms.md` の末尾の「版」と一致することをテストが見る。版が上がると、次の起動で同意画面を出し直す。
4. **同意するまで、アプリは自分からネットワークに何も出さない。** 起動時に始まるループ（サーバーへの接続・更新の確認・ベータ版の遠隔デバッグの問い合わせ）は `terms::wait_accepted` を待ってから始め、利用状況の送信は、設定がオンでも同意があるまで有効にしない。接続・入室・参加・繋ぎ直しのコマンドは、同意が無いうちは断る。
5. **同意を操作できるのはアプリ自身の画面だけ**（権限表で `terms_accept` は画面だけ）。手伝いの人・テスト用の口・遠隔デバッグが、本人の代わりに同意することはできない。
6. **設定画面の一般タブに、規約・ライセンス・プライバシーとセキュリティ・お知らせの行を置く。** 規約とライセンスはアプリに同梱した本文をその場で読む。プライバシーとお知らせはブラウザで開く。開けるのは固定の 2 ページだけで、画面が任意のアドレスを開かせることはできない。お知らせ（`docs/announcements.md`）は、終了・中断・障害の告知を載せる場所で、アプリがサーバーに告知を取りに行く通信は足さない。
   - 却下: 規約の URL を押させるだけにする。同意の時点で本文が手元に無く、準則の言う提供にもならない。
   - 却下: インストーラで同意を取る。上のとおり、全員が通らない。
   - 却下: 同意前も更新の確認だけは動かす。更新の確認で、端末の IP アドレスと版が GitHub に見える。

## Consequences

- **この版から後は、同意が無い端末は何もできない。** 既にベータ版を使っている端末（遠隔デバッグ用の端末を含む）も、更新後の最初の起動で同意画面になり、本人が 1 度同意するまで、サーバーにも更新にも遠隔デバッグにも繋がらない。遠隔の端末は、その場で 1 度同意するか、設定ファイルに `terms_version` を書く必要がある。
- GUI の E2E は、設定ファイルに `terms_version` を書いて起動する（同意済みの利用者として）。初回起動の場面だけが書かない（`tests/e2e/tests/gui.rs`）。
- 規約は日本語のみ。画面の文言は日本語・英語だが、英語の画面でも規約の本文は日本語で出る。
- CLI（`jamjam` バイナリ）は同意画面を持たない。規約は GUI アプリの利用を前提に書いてある。
- 規約を変えて同意を取り直させるときは、`TERMS_VERSION` と `docs/terms.md` の版を同時に上げる（片方だけだとテストが落ちる）。

## 第 1 条（本サービスでできること）

1. jamuru は、招待コードを知っている少人数（1 つのルームに最大 10 人）が、インターネット越しに低い遅延で音声をやり取りして、合奏や練習をするためのアプリです。
2. 音声は、利用者の端末どうしで直接届きます（P2P）。運営者のサーバーは、ルームの出入りと、相手のネットワークアドレスの受け渡し、チャット、設定の手伝いの中継をします。
3. 本サービスは無償です。有料の機能・広告・寄付の受け付けはありません。

## 第 5 条（相手に見える情報）

1. jamuru は P2P です。**ルームに入ると、同じルームの参加者に、あなたの公開 IP アドレス・使っているポート・表示名が見えます。** 同じ LAN にいる相手には、LAN 内のアドレスも見えます。端末識別子は他の参加者には送られません。
2. IP アドレスを見せたくないときは、VPN を使うなど、利用者の側で手段をとってください（遅延が増えることがあります）。
3. 招待コードは、信頼できる相手にだけ伝えてください。コードを知っている人は誰でもルームに入れます。
4. 運営者に見えるもの・保存期間は、「プライバシーとセキュリティ」の説明にあります。

2. 了解を得た範囲を超えて、録音を使わないでください（公開・配信・販売・他の人への提供も、了解の範囲です）。

4. **本サービスは、参加者が録音していることを他の参加者に知らせる表示を持っていません。** 録音されたくないときは、ルームに入る前に、相手に確かめてください。

## 第 8 条（音量と機材）

1. 大きな音は、耳や機材を傷めます。**初めて繋ぐ相手のとき、設定を変えたあと、繋ぎ直したあとは、音量を下げた状態から始めて、ゆっくり上げてください。** 相手の音量や機材は、あなたの側では決められません。
2. スピーカーで使うと、相手の音が自分のマイクに回り込んで、ハウリングやエコーが起きます。ヘッドホンやイヤホンを使うことをおすすめします。
3. 長時間の使用では、適度に休んでください。

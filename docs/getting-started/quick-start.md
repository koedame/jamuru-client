# クイックスタート

jamuruで最初のセッションを始める手順を説明します。

## 0. 初回起動

初めて起動すると、最初に [利用規約](../terms.md) の画面が出ます。内容を読み、2つのチェック（規約への同意、18歳以上または親権者の同意）を入れて **「同意して始める」** を押すと、使い始められます。同意するまで、アプリはサーバーに何も送りません。この画面では、**ルームに入ると同じルームの人にあなたのIPアドレスが見える** ことも伝えています（[プライバシーとセキュリティ](./privacy.md)）。

## 1. オーディオデバイスの設定

1. jamuruを起動
2. 画面右上の **設定**（歯車アイコン）を開く
3. **入力デバイス**（マイク/楽器入力）を選択
4. **出力デバイス**（ヘッドフォン推奨）を選択
5. **バッファサイズ**を調整（デフォルト: 256サンプル）

> [!TIP]
> レイテンシを最小化するため、ASIOドライバ（Windows）またはオーディオインターフェースの専用ドライバを使用することを推奨します。
> ASIO は Steinberg Media Technologies GmbH の商標です。

## 2. ルームを作成する（ホスト）

1. メイン画面で **「ルーム作成」** を選択
2. **招待コード**（9文字英数字）が表示される
3. 招待コードを相手に共有

> [!NOTE]
> ルーム名とパスワードを入力する欄はありません。ルームにパスワードは付きません。

## 3. ルームに参加する（ゲスト）

1. メイン画面で **「コードで参加」** 入力欄に招待コードを入力
2. **「参加」** を押すと接続開始

### 3人以上で使うとき

1つのルームには10人まで入れます。同じ招待コードで全員が入ると、全員が全員と直接つながり、ほかの全員の音が混ざって聞こえます。

- **回線**: 音声は相手1人ごとに送り合うので、使う帯域は人数に比例します。相手1人につき、上り・下りとも約4 Mbps（48 kHz のとき）。3人なら約8 Mbps、10人なら約37 Mbps が上り・下りの両方に要ります
- **全員が同じ版**: 古い版のアプリは1人としかつながりません。3人以上で使うときは、全員が最新版にしてください
- **つながらない相手がいるとき**: 参加者の一覧で、その人の行に「接続中...」や「切断されました」と出ます。ほかの人との音声はそのまま続きます

## 4. セッション中の操作

### 入力レベルの確認

- 画面上の **レベルメーター** で入力音量を確認
- 緑〜黄色が適正、赤はクリッピングの可能性

### ミュート機能

- **マイクアイコン** をクリックしてミュート/ミュート解除
- セッション中に一時的に音声を止めたい場合に使用

### 接続品質の確認

- **RTT**（往復遅延時間）と **ジッター** が表示される
- ジッター値に基づいた **推奨プリセット** が表示される

## 録音と音量の注意

[利用規約](../terms.md) の第7条・第8条と同じ内容です。

- **録音・録画・配信・公開するときは、その音が入るすべての参加者から、録音を始める前に了解を得てください。** jamuruには、録音していることを他の参加者に知らせる表示がありません。
- **大きな音は、耳や機材を傷めます。** 初めて繋ぐ相手のとき、設定を変えたあと、繋ぎ直したあとは、音量を下げた状態から始めて、ゆっくり上げてください。相手の音量や機材は、あなたの側では決められません。
- スピーカーで使うと、相手の音が自分のマイクに回り込んでハウリングやエコーが起きます。ヘッドホンやイヤホンをおすすめします。

## 5. プリセットの選択

ネットワーク環境に応じて最適なプリセットを選択します:

| プリセット | 用途 | ジッター目安 |
|-----------|------|-------------|
| zero-latency | 超低遅延環境（専用線等） | < 1ms |
| ultra-low-latency | LAN環境 | 1-3ms |
| balanced | 標準的なインターネット接続 | 3-10ms |
| high-quality | 高音質優先、高遅延許容 | > 10ms |

> [!TIP]
> 画面に表示される **「推奨設定に切り替え」** ボタンで、現在の接続品質に最適なプリセットに自動変更できます。

## 6. 外観の設定

### ダークモード

1. 設定画面を開く
2. **テーマ** セクションで選択:
   - **ダーク**: 暗い配色
   - **ライト**: 明るい配色
   - **システム**: OSの設定に追従

### 言語設定

- 日本語 / English を選択可能

## 7. セッションの終了

1. **「切断」** ボタンを押す
2. または画面を閉じる

> [!NOTE]
> ホストが切断するとルームは削除されます。
> ゲストは自由に切断・再接続が可能です。

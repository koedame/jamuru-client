## 状態の見方

hover・pressed・focus は CSS の疑似状態なので、Storybook の画面でマウスを乗せる・押す・Tab で移ると見られる。
disabled・error・loading・empty などコードで決まる状態は、部品ごとの Story に並べてある。
ツールバーで言語（English / 日本語）を切り替えられる。
